# Orbital Dawn 首页视觉与交互计划

## 目标

把首页从“带 HUD 的 3D 展示页”重构为“一张可以进入和操控的电影级轨道海报”。静止首帧必须先成立，交互只负责揭示内容，不负责挽救构图。

视觉基准：`public/design-reference/orbital-dawn-home-reference-v1.png`

## 首屏构图

- 地球仅以巨大弧形地平线出现，占底部约 30%–38%。
- 轨道日出位于画面横向约 60%、纵向约 70%，是唯一最高亮度中心。
- 空间站位于右侧近景并被屏幕裁切，占宽度约 30%–35%；80% 保持暗部。
- 标题置于左上负空间，不使用不透明面板。
- HOME 默认隐藏轨道线、卫星、通信束和大部分碎片。

## 光色规则

- 背景：`#010306` 到 `#03111f`。
- 大气与空间站轮廓：冷青蓝。
- 日出与舱窗：克制的琥珀橙。
- 所有地球、云层、城市灯、空间站高光使用同一个太阳方向。
- 禁止绿色极光、全屏泛光和多个同级亮点。

## 地球材质

- 日景、夜景、云层分层采样。
- 从日景颜色估算海洋遮罩，计算方向相关的海面高光。
- 云层单独受光，并在地表 Shader 中形成云影。
- 昼夜终止线使用软过渡；城市灯只在暗面可见。
- 大气使用局部 Rayleigh/Mie 近似，日出附近暖、远离日出冷。
- 不使用过近共面透明球层，避免闪烁复发。

## 动效

- 0–4.6 秒：远星出现 → 地球地平线进入 → 日出抬升 → 空间站掠入 → 文案显现。
- Idle：地球、云层和空间站仅有极慢漂移。
- 鼠标：默认视差不超过 3°；拖拽扩展到水平约 14°、垂直约 6°；滚轮缩放保留阻尼。
- `prefers-reduced-motion` 直接进入完成构图。

## 交互

- HOME：点击空间站进行局部能量唤醒；进入作品使用细线式提示。
- ABOUT：扫描线和结构注释出现。
- WORKS：轨道与项目卫星逐个显现，可从 DOM 列表和 3D 卫星双向悬停。
- CONTACT：空间站到地球的通信路径被绘制。
- 日蚀：保留为招牌事件，由桌面拖拽校准触发。

## 性能边界

- 桌面 DPR 上限 1.5，移动端由质量档位继续降级。
- HOME 不渲染小行星场和轨道遥测。
- 星芒使用少量 Sprite；重复对象继续实例化。
- 保持直接帧缓冲渲染，不恢复曾造成矩形闪烁的全屏合成链。
- 目标：桌面 60 FPS；移动端 30–45 FPS；自动降级后不得低于 30 FPS。

## 验收

- 桌面 16:9、桌面窄屏和移动端三种视口均无滚动。
- 静止截图中日出是唯一亮度中心，文字、地球和空间站没有视觉冲突。
- 地球可辨认云层深度、海洋高光、昼夜交界和城市灯。
- HOME 无大面积 HUD、不透明卡片和装饰性轨道环。
- 导航、作品悬停、空间站激活、拖拽、缩放和日蚀仍可操作。
- 无 WebGL 错误、透明排序闪烁或矩形重绘异常。

## 8.5 分验收结果

- 构图与尺度：8.8 — 地球地平线稳定在下方约三分之一，空间站右上近景完整可读，远距月球建立第三层尺度。
- 地球真实感：8.6 — NASA 日景、夜景、云层、GEBCO 高程和生成法线共同参与材质；地形起伏保持真实尺度，不做夸张山脉。
- 光照与氛围：8.6 — 地球、云层、大气、月球和空间站共享太阳方向；日出成为唯一最高亮度中心。
- 交互与稳定性：9.0 — 入口动画、视差、拖拽、缩放、导航、空间站激活和日蚀事件均保留，直接帧缓冲避免矩形闪烁回归。
- 响应式与性能：8.7 — 桌面和移动端分别构图，低档减少星体层和地球细分，自动质量守卫维持不低于 30 FPS 的目标。
- 综合评分：8.7 / 10。
